Solyx 在你的電腦上執行。Solyx 專案沒有任何接收你的對話、金鑰、持股或委託的伺服器，沒有 Solyx 帳號，應用程式與本網站也都沒有分析或廣告追蹤。離開你電腦的資料，會用你自己的金鑰直接送到你設定的服務，或送往〈[哪些資料會到達 Solyx 專案](#what-reaches-the-solyx-project)〉列出的少數幾處。

本政策適用於 Solyx 桌面應用程式、它的更新來源，以及本網站 `usesolyx.trade`，由維護者 Chia1104 負責。聯絡方式見〈[聯絡方式](#contact)〉。

## 保存在你電腦上的資料 [#what-stays-on-your-computer]

Solyx 把資料存在你電腦上的兩個資料夾：資料資料夾（macOS 為 `~/Library/Application Support/Solyx`，Windows 為 `%APPDATA%\Solyx`）與設定資料夾 `~/.solyx`。**設定 → 關於** 會顯示這兩個位置。其中包含：

- **你的資料**：自選、提案、模擬帳戶的委託與成交、排程任務、主題、你跑過的回測、對話與 Agent 從你附加的檔案讀到的內容（縮給模型看的圖片、文字檔與 PDF 抽出的文字）、Agent 的記憶、報告與預測、收集的新聞，以及快取的行情。
- **你的設定**：`~/.solyx/config.json`，旁邊是你的 skills、策略、`AGENTS.md` 與 `mcp.json`。選擇券商帳戶後，設定檔會記錄委託送往的帳號。
- **金鑰、登入資料、交易授權、你允許的策略版本與已配對的瀏覽器**：由作業系統的金鑰儲存加密保存（macOS 為鑰匙圈，Windows 為 DPAPI，Linux 為 keyring），絕不會寫入設定檔、日誌或備份。
- **券商 SDK 的日誌**：富邦的 SDK 會在資料資料夾寫入自己的日誌，內容可能包含你的身分證字號與帳戶資料。
- **兩個隨機識別碼**：一個是 Solyx 為這次安裝產生的，一個是它的更新程式產生的。兩者都不是由你或你的電腦資訊推導而來。

新聞預設保留 90 天（新聞）或 30 天（社群），可自行調整。其餘資料會一直保留，直到你刪除。

## Solyx 送出什麼、給誰 [#what-solyx-sends-and-to-whom]

Solyx 只把資料送到你設定的服務，直接從你的電腦送出，而且只送各服務需要的內容。每項服務都是獨立的公司，有自己的條款與隱私權政策，規範它如何處理收到的資料。

| 服務                   | 收到的內容                                                                                                                                                                                                                                                                           |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 行情來源（富果或富邦） | 你的金鑰，以及你看圖、報價、自選或持有的標的                                                                                                                                                                                                                                         |
| 你的券商（富邦）       | 你的登入資料、憑證與 API 金鑰，以及你確認或交易授權送出的委託；它回傳你的餘額、庫存與成交                                                                                                                                                                                            |
| FinMind                | 你設定的 token（若有），以及 Solyx 讀取其數據的標的代號                                                                                                                                                                                                                              |
| 你的模型供應商         | 你的訊息與 Agent 的回覆、你附加在訊息中的檔案（圖片，以及文字檔與 PDF 的文字）、每則訊息的情境（時間、你的時區、模擬或實單、畫面上的內容、你點名的標的）、你的 `AGENTS.md`、Agent 記憶的索引，以及它使用工具的結果，其中可能包含你的現金、庫存、委託與提案、新聞、公告與你的策略檔案 |
| 你的網路搜尋供應商     | 你追蹤的標的與主題的搜尋、Agent 的搜尋，以及它讀取的網頁網址                                                                                                                                                                                                                         |
| 你的決策模型           | 新聞內文與相關標的、主張與其引文，以及在設為 **自動判斷** 的對話中由它判斷的 shell 指令與策略程式                                                                                                                                                                                    |
| 你的嵌入模型供應商     | 新聞的標題與開頭。你自己的文字（搜尋、報告、記憶）只會送到你設定的 Ollama 端點，絕不會送給 OpenAI                                                                                                                                                                                    |
| 你的備份 bucket        | 以你的密語封存的資料。不需密語即可讀取的只有：應用程式名稱與版本、安裝識別碼，以及每次備份的時間                                                                                                                                                                                     |
| 你的 OTLP 端點         | 應用程式運作的追蹤與日誌：模型、工具名稱、token 數、費用、事件與錯誤類型，絕不包含對話內容                                                                                                                                                                                           |
| 你加入的 MCP server    | 它所處理的工具呼叫的參數                                                                                                                                                                                                                                                             |

你的模型供應商看得到 Agent 讀到的內容，所以 Agent 查看帳戶時，供應商也看得到你的餘額與庫存。金鑰與密碼絕不會送給它。追蹤資料絕不包含對話內容。

### 公開來源 [#public-sources]

Solyx 也會讀取不需金鑰的公開資料：證交所與櫃買中心的開放資料、投信投顧公會、中華民國統計資訊網與主計總處，以及 PTT 的 Stock 板。和任何網站一樣，它們會看到你的 IP 位址與查詢的內容。在 PTT 搜尋新聞時，會帶出你持有與自選的標的名稱。新聞預設每 72 小時收集一次，可在 **設定 → 排程** 調整或停止。

### 登入 [#signing-in]

登入模型供應商（ChatGPT、OpenRouter、GitHub Copilot、xAI 或 Meta）時，你是在供應商自己的頁面登入。Solyx 透過只綁定 `127.0.0.1`、僅在等待登入期間開啟的監聽埠接收登入後的 token 或金鑰，並與其他金鑰一起保存。使用 ChatGPT 登入時，會讓 OpenAI 知道這次安裝的識別碼，以及用戶端是 Solyx。

### 已配對的瀏覽器 [#paired-browsers]

**提供給已配對的瀏覽器** 在你於 **設定 → 裝置** 打開之前都是關閉的。打開後，Solyx 會在 `127.0.0.1` 上把工作區提供給你配對的瀏覽器，它們看得到工作區顯示的一切：你的帳戶、對話、研究等等。它不回應其他電腦；別處的瀏覽器只能透過你自己開的通道（例如 SSH）連上。Solyx 會為每個瀏覽器保存它的名稱、權杖的雜湊值，以及通行金鑰的公開金鑰，和你的其他金鑰放在一起。通行金鑰本身留在瀏覽器或你的密碼管理工具裡。

## 哪些資料會到達 Solyx 專案 [#what-reaches-the-solyx-project]

### 檢查更新 [#update-checks]

Solyx 會在啟動一分鐘後、之後每六小時，以及你要求時，向 `download.usesolyx.trade` 檢查是否有新版本。請求會帶有你的 IP 位址、更新程式的隨機識別碼與通用的用戶代理字串，並指名適用你系統的檔案。更新來源存放在 Cloudflare R2。本專案不會用這些請求識別或追蹤你。可在 **設定 → 關於 → 自動檢查更新** 關閉。在 macOS 上，新版本會開啟 GitHub 上的發布頁面，受 GitHub 隱私權政策規範。

### 當機報告 [#crash-reports]

當機報告預設關閉，需由你在首次設定或 **設定 → 關於** 開啟。開啟後，Solyx 在當機或遇到非預期錯誤時，會透過 [Sentry](https://sentry.io/privacy/) 傳送報告。

- **報告包含**：錯誤的類型、訊息與發生在程式碼的位置；Solyx、Electron 與作業系統的版本；你電腦的處理器、記憶體、螢幕尺寸、顯示卡、語系與時區；以及應用程式啟動與結束的時間。
- **Solyx 會移除**：你的金鑰、路徑中你的家目錄名稱、請求資料、使用者資訊、主控台與網路的操作紀錄，以及當機傾印檔。Sentry 被設定為不保存你的 IP 位址與電腦名稱。報告不包含你的對話、庫存或委託，但錯誤訊息會指出哪裡出錯。
- **報告的用途**：僅用於找出並修正錯誤，只有維護者能看到，保存期間依 Sentry 的保存設定。關閉當機報告後立即停止傳送。

### 本網站 [#this-website]

本網站不設定 cookie、不使用分析工具，字型也由本站自行提供。它會在你瀏覽器的本機儲存空間記住你選的佈景主題，以及你關閉過的提示。搜尋在你的瀏覽器中執行。提供本站服務的 Cloudflare 會為了傳送網站內容與防範濫用而處理你的 IP 位址與請求，受 [Cloudflare 隱私權政策](https://www.cloudflare.com/privacypolicy/)規範。安裝檔從 GitHub 下載，受 [GitHub 隱私權聲明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)規範。

### 你聯絡本專案時 [#when-you-contact-the-project]

你寄信給本專案或開 issue 時，本專案會收到你送出的內容，並僅用於回覆你。GitHub 上的 issue 是公開的，請勿在其中留下個人資料。

## 你的選擇 [#your-choices]

- **關閉功能**：當機報告、檢查更新、新聞收集，以及你設定的每項服務，都可以在 **設定** 中關閉或移除。金鑰與登入資料可以逐一移除。
- **刪除資料**：**設定 → 儲存空間** 可以清除對話、記憶、新聞、研究、自選與快取的行情。你 bucket 中的備份由你自行在該處刪除。
- **解除安裝不會刪除資料**：若要完全移除，也請刪除資料資料夾與 `~/.solyx`，以及系統鑰匙圈中 Solyx 的項目。每日建置版本另有自己的資料，名稱為 Solyx Nightly 與 `~/.solyx-nightly`。
- **你的權利**：依中華民國個人資料保護法，你可以請求查詢、閱覽、製給複製本、補充或更正、停止蒐集處理利用，或刪除本專案所持有關於你的個人資料，例如當機報告或電子郵件。請寄信到下方地址；當機報告不含姓名，請附上當機發生的時間以便查找。

由你設定的服務所持有的資料，請向該服務提出。

## 安全 [#security]

金鑰由作業系統加密，備份以 AES-256-GCM 封存，金鑰由你的密語衍生。Solyx 內建的來源與服務都透過 HTTPS 連線；你自行輸入的位址，例如 Ollama 伺服器或 OTLP 端點，則依你提供的位址連線。沒有任何軟體是絕對安全的，請妥善保管你的電腦、密語與金鑰。

## 適用對象 [#who-solyx-is-for]

Solyx 適用於依其所在地法令可持有證券帳戶的成年人，並非以兒童為對象，本專案也不會在知情的情況下接收兒童的資料。

## 政策的變更 [#changes-to-this-policy]

當 Solyx 送出的內容改變時，本政策也會隨之變更。變更會公告於本頁並更新上方日期，專案的版本庫保留每一個先前的版本。

本政策以英文與繁體中文發布；兩者如有歧異，以繁體中文版本為準。
