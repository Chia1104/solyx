title: The agent
description: What the agent reads, what it may do on its own, and what it never does.
---

The agent talks about what is on your screen. A conversation carries the listing you are looking at; name another with `@` and call a skill with `/`.

## What it reads

- **Figures it cites rather than works out.** Its tools read candles, indicators, fundamentals, investor flows, economic figures, the calendar, news and your account. The app computes growth, margins and multiples, so the model quotes them.
- **Its own analysis.** Scripts it writes run in a sandbox that reads market data and the account and reaches nothing else.
- **The web,** through your Firecrawl, Exa or Tavily key.
- **What it learned of you.** Memories carry over between conversations; you can read, edit and forget each one.

## How its actions are allowed

Each conversation picks how the agent's tool calls and shell commands are allowed.

| Mode         | What runs without you                                                                                                                       |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------- |
| Ask first    | Nothing: tool calls and shell commands wait for you to allow them.                                                                          |
| Allow for me | Shell commands judged harmless, reading pages this conversation found, and saving what it learns about you to memory. Everything else asks. |
| Don't ask    | Tool calls and shell commands.                                                                                                              |

No mode lets the agent confirm an order. Its tools only propose, and only your click in the app confirms.

## Your extensions

- **Skills** are playbooks in `~/.solyx/skills/`, offered as `/` commands.
- **`AGENTS.md`** in the same folder holds standing instructions the agent reads every run.
- **`mcp.json`** connects MCP servers. Each of their tools is off, ask or auto.

## Schedules

A task sends the agent a message every so often, at a time of day on the days a market trades, or once something the app watches has changed. Runs go on while the app sits in the menu bar. A scheduled run asks first or allows for you; it never runs in Don't ask.

## Models

Use an API key for a model provider or sign in with ChatGPT, and pick the model and thinking level per conversation.
