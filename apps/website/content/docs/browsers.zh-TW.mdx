Solyx 可以把工作區提供給你配對過的瀏覽器，讓你從另一個視窗或另一台電腦看盤、和 Agent 對話、跑回測。這個功能在你打開之前都是關閉的，而且只在這台電腦自己的位址上提供。

## 打開這個功能 [#switching-it-on]

在 **設定 → 裝置** 打開 **提供給已配對的瀏覽器**。Solyx 會在 `http://localhost:18321/` 提供工作區；要換連接埠，請在 [config.json](/zh-TW/docs/files#what-configjson-holds) 設定 `remote.port`。

它只在 `127.0.0.1` 上監聽，也只回應指名這台電腦的請求，所以同一個網路上的其他裝置都連不到。要從另一台電腦使用，請用 SSH 轉送連接埠，再在那台電腦開啟同一個位址：

```bash
ssh -L 18321:127.0.0.1:18321 your-computer
```

## 配對瀏覽器 [#pairing-a-browser]

<Steps>
  <Step>
    在 **設定 → 裝置** 按
    **顯示代碼**。代碼的效期是五分鐘，只能用一次，輸錯五次就會失效。
  </Step>
  <Step>**在那個瀏覽器開啟位址**，輸入代碼，並為這個瀏覽器命名。</Step>
  <Step>
    **加入通行金鑰**，如果你想從這個瀏覽器送出委託。Solyx
    只會在這時、剛配對完的當下提供這個選項。
  </Step>
</Steps>

<Screenshot
  file="devices/pairing.png"
  alt="配對瀏覽器：輸入設定裡的代碼，並為瀏覽器命名"
/>

瀏覽器會保有自己的權杖。Solyx 只保留它的雜湊值，並和你的金鑰一起加密，所以修改 Solyx 的檔案無法配對任何瀏覽器。在 **設定 → 裝置** 按 **解除配對**，會立刻中斷那個瀏覽器的連線。

## 瀏覽器能做什麼 [#what-a-browser-can-do]

| 已配對的瀏覽器               | 能不能                            |
| ---------------------------- | --------------------------------- |
| 檢視工作區、圖表、新聞與研究 | 可以                              |
| 和 Agent 對話                | 可以，一律以 **先詢問** 執行      |
| 建立提案、跑回測             | 可以                              |
| 送出提案、取消委託或停損停利 | 要有通行金鑰，而且每次都要解鎖    |
| 放行 Agent 的呼叫            | 不行：請在執行 Solyx 的電腦上回覆 |
| 重試被停下的執行             | 不行：只有執行 Solyx 的電腦能重試 |
| 變更設定、下單鎖定或交易授權 | 不行                              |

不論電腦設定的是哪一種模式，瀏覽器送出的訊息都以 **先詢問** 執行，所以在你可能不在電腦前的時候，它的對話不會有任何東西未經詢問就執行。Agent 在那裡提出的委託，仍會和其他提案一樣交給你的[交易授權](/zh-TW/docs/orders/mandate)判斷。

## 通行金鑰 [#passkeys]

<Screenshot
  file="devices/passkey.png"
  alt="配對後，Solyx 提供加入通行金鑰，讓瀏覽器能送出與取消委託"
/>

通行金鑰讓瀏覽器能送出提案，以及取消委託或停損停利。每個動作都要你解鎖通行金鑰，而它的簽章只涵蓋那一筆提案或委託上的那一個動作，兩分鐘內有效、只能用一次，所以就算瀏覽器的權杖被拿走，也送不出任何委託。

通行金鑰綁定的是名稱，而瀏覽器不會把它綁定到 IP 位址，所以 Solyx 只在 `localhost` 提供通行金鑰，`127.0.0.1` 不行。沒有通行金鑰就配對的瀏覽器，會顯示送出要在電腦上進行；重新配對就能加入。
