title: 回測
description: Agent 的回測怎麼成交、怎麼計算成本，以及怎麼避免偷看未來。
---

Agent 可以在一檔股票的歷史上測試交易規則。回測在你的電腦上執行，用的是 Solyx 本來就會讀的 K 線，每次都走同一套引擎。

## 不偷看未來 [#no-look-ahead]

<Steps>
  <Step>
    **在 K 線收盤時判讀規則**。交叉的意思是前一根 K
    線在下方或相等，這一根在上方。`highest` 與 `lowest` 只看目前這根之前的 K
    線。
  </Step>
  <Step>**在下一根 K 線開盤時動作**，並依滑價往對你不利的方向調整價格。</Step>
</Steps>

規則永遠看不到它交易的那根 K 線。

## 價格 [#prices]

技術指標、停損與買進持有的比較，讀的是[還原價](/zh-TW/docs/data/market-data#as-traded-or-adjusted)，並換算回每根 K 線自己的價格水準，所以除息永遠不會看起來像崩跌。委託以實際成交過的價格成交，持有股數會在分割或除權息日跟著調整。

## 成交 [#fills]

- **只做多**。買進時把現金全部用來買整股，並預留手續費；賣出時全部賣出。
- **滑價**是從開盤價起算的跳動單位數，預設 1，最多可設到 20。
- **鎖漲跌停**。台股某根 K 線的最高價等於最低價、且收盤高於參考價時，視為鎖漲停，買進不會成交；鎖跌停時，賣出不會成交。

## 成本 [#costs]

<Tabs items={["台股", "美股"]}>
  <Tab value="台股">

    | 成本   | 預設                                                         |
    | ------ | ------------------------------------------------------------ |
    | 手續費 | 買賣各 0.1425%，最低新台幣 20 元                             |
    | 證交稅 | 股票 0.3%；代號以 `00`、`01` 或 `02` 開頭的（ETF、REIT 與 ETN）為 0.1% |
    | 滑價   | 1 個跳動單位                                                 |

  </Tab>
  <Tab value="美股">預設沒有手續費與稅，滑價 1 個跳動單位。</Tab>
</Tabs>

$$
\begin{aligned}
\text{commission} &= \max(\text{rate} \times \text{value},\ \text{minimum}) \\
\text{proceeds} &= \text{value} - \text{commission} - \text{value} \times \text{tax}
\end{aligned}
$$

手續費率與稅率最高可設到 1%。起始資金預設為 1,000,000，可另行設定。

## 回報的數字 [#what-it-reports]

| 數字     | 意義                                                                                                  |
| -------- | ----------------------------------------------------------------------------------------------------- |
| 總報酬   | 期末價值相對期初                                                                                      |
| 年化報酬 | $$\left( \frac{\text{end}}{\text{start}} \right)^{365.25 / \text{days}} - 1$$；不到 28 天的回測不計算 |
| 最大回撤 | 從高點下跌最深的幅度                                                                                  |
| 交易次數 | 已平倉的交易；仍持有的部位不計                                                                        |
| 勝率     | 已平倉交易中獲利的比例                                                                                |
| 賺賠比   | 平均獲利相對平均虧損                                                                                  |
| 曝險時間 | 持有部位的 K 線所佔比例                                                                               |
| 買進持有 | 同一段期間全程持有的結果，附它自己從前一日收盤起算的回撤                                              |

回測可以在某個日期切成樣本內與樣本外兩段，讓在其中一段調好的規則，用另一段來評判。已平倉交易少於 20 筆時，Agent 視為說明不了什麼。它的腳本最多回溯 10 年、最多 5 檔。
