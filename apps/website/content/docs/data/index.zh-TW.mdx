---
title: Solyx 怎麼計算
description: 畫面上每個數字從哪裡來，以及 App 依什麼規則算出它。
---

Solyx 顯示的、或 Agent 引用的每個數字，都是在你的電腦上，由 App 自己的程式，從直接向各來源讀取的資料算出來的。

- **App 計算，模型引用**。技術指標、關鍵價位、成長率、利潤率、估值倍數、籌碼與基準率都由程式算出，圖表和 Agent 用的是同一套，所以回覆引用的是你畫面上的數字，而不是模型自己算出來的。
- **價格照實際成交**。圖表與技術指標顯示實際成交的價格，除權息與分割造成的缺口也照樣保留。只有跨越歷史的比較，也就是回測與類股輪動圖，才會還原。
- **已收盤的交易日會保留**。供應商公布的已收盤交易日資料，會快取在你的電腦上，絕不重複下載；仍在交易中的部分則會重新讀取。
- **不超出你的方案**。請求會依每把金鑰所屬方案的上限調整間隔，即時訂閱則由所有需要它的視窗共用。
