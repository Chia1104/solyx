每個成長率、利潤率與估值倍數都由 App 自己算出，所以 Agent 是引用數字，而不是在腦中計算。Agent 讀到的金額以百萬為單位，百分比取到小數第一位，變動取到小數第二位，缺少的數字寫成 n/a。

## 財報 [#statements]

財報、月營收與股利由 FinMind 提供。

| 項目                   | 往回涵蓋 | 快取時間 |
| ---------------------- | -------- | -------- |
| 損益表                 | 5 年     | 12 小時  |
| 資產負債表與現金流量表 | 3 年     | 12 小時  |
| 月營收                 | 36 個月  | 12 小時  |
| 股利                   | 5 年     | 12 小時  |

### 整理資料 [#cleaning-the-rows]

- 沒有營收的季度會捨棄，沒有資產總額的資產負債表也一樣。
- 淨利採歸屬於母公司業主的淨利；缺少這一項時，改用稅後淨利。
- 現金流量是以年初至今的累計數申報，所以每一季是它的累計數減去前一季的累計數；第一季照申報數取用。前一季缺漏的季度沒有數字。
- 資本支出是取得不動產、廠房及設備所支付的現金。
- 一筆股利的現金股利，是盈餘與法定盈餘公積兩部分相加；股票股利也一樣。完全沒有配發的會捨棄。

### 數字何時公開 [#when-a-figure-became-public]

每一季以申報期限當天視為已知，所以過去某天的估值倍數，只用到那天以前已公布的資料。

| 季度   | 期限            |
| ------ | --------------- |
| 第一季 | 5 月 15 日      |
| 第二季 | 8 月 14 日      |
| 第三季 | 11 月 14 日     |
| 第四季 | 隔年 3 月 31 日 |
| 月營收 | 次月 10 日      |

## 衍生數字 [#derived-figures]

| 數字                       | 算法                                                                                         |
| -------------------------- | -------------------------------------------------------------------------------------------- |
| 成長率                     | $$\frac{\text{now} - \text{before}}{\lvert \text{before} \rvert}$$，所以由虧轉盈會顯示為成長 |
| 營收與 EPS 年增率          | 與十二個月前的那一季相比                                                                     |
| 營收季增率                 | 與前一季相比                                                                                 |
| 月營收                     | 與去年同月，以及上個月相比                                                                   |
| 毛利率、營業利益率、淨利率 | 該項 ÷ 營收                                                                                  |
| 近四季 EPS                 | 最近四季相加；缺任何一季就沒有                                                               |
| 流動比率                   | 流動資產 ÷ 流動負債                                                                          |
| 負債比                     | 負債總額 ÷ 資產總額                                                                          |
| 自由現金流                 | 營業現金流 − 資本支出，分別以單季與近四季計算                                                |
| 近一年現金股利             | 除息日落在過去一年內的現金股利                                                               |
| 目前本益比                 | 最新的週收盤價 ÷ 最新的近四季 EPS                                                            |
| 歷史本益比                 | 三年來每週收盤價 ÷ 當時已公布的近四季 EPS，取最低、中位數與最高                              |

歷史本益比會排除近四季 EPS 小於或等於零，或已公布不到四季的週。前一個數字為零或缺漏時，成長率與利潤率留空。

交易所自己的本益比、殖利率與股價淨值比，照證交所與櫃買中心公布的數值取用，Solyx 不會重新計算。

### 同業 [#peers]

一檔股票的同業，是同產業的其他公司。每個估值倍數，Solyx 都會給出同業的中位數，以及同業中低於這檔的比例。

### 公司 [#the-company]

- **市值**是已發行股數 × 最近一個已收盤交易日的收盤價。
- **週轉率**是那個交易日的成交量 ÷ 已發行股數。
- **公司治理**註記先列出董監事質押股數，再列出裁罰、交易所罰款與經營權異動。

  </Accordion>

    基金的收益分配隨 FinMind

  </Accordion>

## 籌碼 [#investor-flows]

籌碼顯示誰在交易一檔台股：外資、投信、自營商與自營商避險。FinMind 的外資自營商算作外資。

| 數字       | 算法                                                                           |
| ---------- | ------------------------------------------------------------------------------ |
| 買賣超     | 買進 − 賣出，分別計算最新一個交易日、一週（5 個交易日）與一個月（20 個交易日） |
| 連續天數   | 與最新交易日同方向的連續交易日數；買超為正                                     |
| 餘額變化   | 最新的融資、融券餘額或外資持股，減去 1、5 與 20 個交易日前的數值               |
| 融資使用率 | 融資餘額 ÷ 融資限額                                                            |
| 券資比     | 融券餘額 ÷ 融資餘額                                                            |
| 期貨       | 各法人在台指期的多方未平倉 − 空方未平倉                                        |

個股的數字以張為單位，整體市場的買賣以新台幣百萬元計，外資持股以百分比表示。資料只涵蓋部分日子的週或月，在圖表上會顯示為未知。籌碼在台北時間 15:00 到 21:00 之間公布，所以每次取得的結果會保留到 FinMind 下一次公布，也就是 15:30、18:30 或 21:30，最多保留一天。籌碼資料讀取一年。

## 總經數據公布 [#economic-releases]

台股的公布日程來自中華民國統計資訊網（stat.gov.tw），數值來自主計總處的統計資料庫。

| 發布項目         | 機關           | 主計總處提供的數值   |
| ---------------- | -------------- | -------------------- |
| 消費者物價指數   | 主計總處       | CPI 與核心 CPI，指數 |
| 國內生產毛額概估 | 主計總處       | GDP 成長率，%，季    |
| 經濟預測         | 主計總處       | 無                   |
| 海關進出口貿易   | 財政部         | 出口與進口，百萬美元 |
| 工業生產         | 經濟部         | 指數                 |
| 外銷訂單         | 經濟部         | 百萬美元             |
| 景氣對策信號     | 國家發展委員會 | 燈號分數，分         |
| 採購經理人指數   | 國家發展委員會 | 無                   |

- 日期寫成「N 日前」的發布會標為期限，否則就是確定的日期。
- 每個數值對應到期間不晚於該次發布的最新一筆數字。
- 指數與金額會與去年同期相比，算出年增率；比率與分數則不算。
- 還沒公布的期間會回傳 0，所以每個序列都止於最後一個真實數字；項目名稱有變動的表格會直接失敗，而不是拿另一個數字充數。
- 日程快取 12 小時，數值快取一小時。Agent 讀取最近 13 期。

### 美股 [#us-economic-releases]

登入長橋後，美國的公布日程與數值來自長橋的總經資料，每個數值都附上市場預期。長橋只排定約三週內的公布，更遠的日期還不會出現在行事曆上。

| 發布項目         | 數值                                     |
| ---------------- | ---------------------------------------- |
| 利率決議         | 聯準會目標區間的中值，%                  |
| 消費者物價指數   | CPI 與核心 CPI，年增率                   |
| 個人所得與支出   | PCE 與核心 PCE 物價，年增率              |
| 就業報告         | 非農新增就業（千人）、失業率、時薪年增率 |
| 零售銷售         | 月增率                                   |
| ISM 製造業指數   | 指數                                     |
| ISM 服務業指數   | 指數                                     |
| 國內生產毛額概估 | 年化季增率                               |
| 生產者物價指數   | 年增率                                   |
| 初領失業救濟金   | 千件，以該週最後一天為期間               |
| 消費者信心       | 密西根大學初值，指數                     |

- 每個數值旁都列出市場預期；下一期排定公布後，也會列出它的預期。
- 利率決議以宣布當天為期間。
- 總覽美股的「大盤」分頁另外列出 VIX，以及財政部公布的 2 年期、10 年期美債殖利率與兩者的利差；Agent 讀美股總經時也會一併讀到最近 10 天的殖利率。

## 行事曆 [#the-calendar]

總覽的行事曆彙整未來 90 天的：

- **財報**：台股的季報依申報期限，月營收依每月 10 日；
- **股利**：除息日、發放日與除權日；配發沒有給日期時，改用交易所自己的除權息公告；
- **股東會**：常會或臨時會，以及是否改選董監事；
- **交易限制**：從第一天起列出，實施中的則列在今天；
- **休市**與**總經數據公布**，過了當天之後還會再列七天；
- **報告記下的事件**。

每個事件分為已確定、期限前或預期三種。Agent 預設讀取未來 30 天，要求時最多可讀到 90 天。
