### 交易單位 [#lots]

一張是 1,000 股。零股是 1 到 999 股，一筆委託不是整張就是零股，不能混合。零股只能下限價單。

### 成本 [#costs]

| 成本   | 費率                                                   |
| ------ | ------------------------------------------------------ |
| 手續費 | 成交金額的 0.1425%，最低新台幣 20 元，元以下無條件捨去 |
| 證交稅 | 0.3%；ETF、REIT 與 ETN 為 0.1%                         |

下單面板會在每筆委託的價金旁寫出手續費，賣出時再加上證交稅。

### 交割 [#settlement]

成交後第二個交易日（T+2）與你的銀行交割。可用於買進的金額，是交割銀行的餘額，再扣抵所有已做的交易後的結果：先前交易日的交易照券商的計算，今天的成交與仍在委託中的買單，則以最高的手續費與稅扣除，所以只會估低。

### 漲跌停 [#price-limits]

漲跌幅取自交易所每個交易日自己公布的數字（證交所與櫃買中心），而不是以 ±10% 自行推算，而且只適用於它所屬交易日的下一個交易日。公布的漲停價為 9,999.95 的標的沒有漲跌幅限制。市價單以漲停價計算金額，也就是它最多可能成交的價格，所以還不知道漲跌停價時會被拒絕。

## 美股 [#us]

一美元以下的跳動單位是 0.0001，一美元起是 0.01。委託須為整數股。

## Solyx 自己設的上限 [#limits-solyx-sets]

| 上限                 | 數值                                |
| -------------------- | ----------------------------------- |
| 單筆委託上限         | 新台幣 1,000,000 元或 30,000 美元   |
| 模擬帳戶的起始現金   | 新台幣 1,000,000 元與 30,000 美元   |
| 真實帳戶可交易的時段 | 一般交易時段                        |
| 模擬帳戶可交易的時段 | 所有時段                            |
| 提案何時失效         | 它的交易時段已過，或價格變動超過 3% |
| 停損停利最長盯價時間 | 60 天                               |
