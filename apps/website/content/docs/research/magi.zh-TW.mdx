---
title: MAGI
description: 三個單元，各自是一個在你所選模型上的人格，對預測與下單提案投票。
---

你可以選擇由誰來評斷 Agent 的預測與提案：由 Agent 自行決定，或交給 MAGI。MAGI 會把預測的每個情境、以及每筆下單提案都付諸表決。三個單元各自是一個在你所選模型上的人格，獨立判斷：

| 單元                   | 衡量                                         |
| ---------------------- | -------------------------------------------- |
| **MELCHIOR·1**，科學家 | 數據與證據顯示了什麼                         |
| **BALTHASAR·2**，母親  | 可能失去什麼，以及按兵不動是否才是證據要求的 |
| **CASPER·3**，女人     | 群眾現在想要什麼，以及按兵不動會錯過什麼     |

兩票即可決。可決的委託仍然要等你確認。

## 付諸表決的事 [#what-is-put-to-a-vote]

<Tabs items={["下單提案", "預測"]}>
  <Tab value="下單提案">
    一個提訴，只在提案通過所有風控檢查後才表決。被否決的委託不會成為提案；可決的則和其他提案一樣等你確認。
  </Tab>
  <Tab value="預測">
    每個情境各自是一個提訴：收盤價落在它的區間的可能性，比基準率所說的更高。沒有基準率的預測不會表決，且無論結果如何都會保留。
  </Tab>
</Tabs>

單元看不到 Agent 自己的機率、方向或計畫，只看得到證據，所以它們評判的是論據，而不是結論。[各單元讀些什麼](/zh-TW/docs/data/forecasts#the-magis-vote)。

## 設定 [#setting-them-up]

在 **設定 → 模型** 把 **決策模式** 設為 **MAGI**，並為每個單元選擇模型，或讓單元沿用對話的模型。每個單元都用你自己的金鑰，所以一次表決要花三次模型呼叫。
