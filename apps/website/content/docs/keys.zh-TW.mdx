---
title: 金鑰與來源
description: Solyx 讀取哪些資料、從哪裡讀，以及各自需要你準備什麼。
---

每把金鑰都是你的，並加密存在你的電腦上。有行情來源和一個模型就能開始；其餘的會增加 Agent 能做的事。請求直接從你的電腦送到各服務商。

| 用途                             | 來源                                          | 你要準備                                              |
| -------------------------------- | --------------------------------------------- | ----------------------------------------------------- |
| 台股報價與 K 線                  | 富果，或富邦                                  | 富果 API 金鑰，或富邦的 SDK 與登入                    |
| 財報、股利與籌碼                 | FinMind                                       | 不需要；有 token 可提高上限                           |
| 交易所清單、重大訊息與內部人轉讓 | 證交所與櫃買中心的開放資料                    | 不需要                                                |
| 經濟數據發布與數值               | 中華民國統計資訊網與主計總處                  | 不需要                                                |
| Agent 的模型                     | 你選擇的模型服務商                            | API 金鑰，或登入 ChatGPT、GitHub Copilot、xAI 或 Meta |
| 網路搜尋與新聞來源               | Firecrawl、Exa 或 Tavily                      | API 金鑰                                              |
| 判讀主張、新聞與指令（決策模型） | TypeSafe、Cloudflare Workers AI 或 OpenAI     | API 金鑰                                              |
| 語意搜尋與新聞分群（嵌入模型）   | OpenAI，或你電腦上的模型（Ollama、LM Studio） | API 金鑰，或不需要                                    |

## 券商 SDK

券商 SDK 永遠不會跟著 Solyx 一起發布。要使用富邦，請自行下載它的 `fubon-neo` SDK，並在 **設定 → 券商** 讓 Solyx 指向它；App 會從你選的資料夾載入它，並在獨立的程序中執行。

## 方案與上限

服務商會依你的方案限制用量，所以 Solyx 每個金鑰與方案只保持一個連線，並依方案調整請求的間隔。已收盤的交易日會快取在你的電腦上，圖表不會重複下載。

## 你自己指定的端點

只有你能把模型服務商的請求轉送到其他端點（例如你自己的閘道）、為 App 的追蹤與日誌指定端點，或指定接收備份的儲存桶。備份離開電腦前會用你的密語封存，且絕不包含任何金鑰。
