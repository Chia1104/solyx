---
title: Keys and sources
description: What Solyx reads, where from, and what you bring for each.
---

Every key is yours and is saved encrypted on your computer. Market data and a model are enough to start; the rest add to what the agent can do. Requests go straight from your computer to each provider.

| For                                               | Source                                                  | You bring                                                        |
| ------------------------------------------------- | ------------------------------------------------------- | ---------------------------------------------------------------- |
| Taiwan quotes and candles                         | Fugle, or Fubon                                         | A Fugle API key, or Fubon's SDK and login                        |
| Fundamentals, dividends and investor flows        | FinMind                                                 | Nothing; a token raises the limit                                |
| Exchange lists, filings and insider transfers     | TWSE's and TPEx's open data                             | Nothing                                                          |
| Economic releases and their figures               | Taiwan's statistics portal and DGBAS                    | Nothing                                                          |
| The agent's model                                 | A model provider of your choice                         | An API key, or a sign-in to ChatGPT, GitHub Copilot, xAI or Meta |
| Web search and news outlets                       | Firecrawl, Exa or Tavily                                | An API key                                                       |
| Reading claims, news and commands (decisions)     | TypeSafe, Cloudflare Workers AI or OpenAI               | An API key                                                       |
| Search by meaning and grouping stories (embedder) | OpenAI, or a model on your computer (Ollama, LM Studio) | An API key, or nothing                                           |

## Broker SDKs

Broker SDKs never ship with Solyx. To use Fubon, download its `fubon-neo` SDK yourself and point Solyx at it; the app loads it from the folder you choose and runs it in a process of its own.

## Plans and limits

Providers enforce the limits of your plan, so Solyx keeps one connection per key and plan and spaces its requests to match. Closed sessions are cached on your computer, so a chart does not download them twice.

## Endpoints you choose

Only you can send a model provider's requests to another endpoint, such as your own gateway, name an endpoint for the app's traces and logs, or name the bucket that receives your backups. Backups are sealed under your passphrase before they leave the computer and never hold a key.
