Solyx 收集你持有與自選標的的新聞，把同一事件的轉載與改寫歸成一則，再由決策模型判讀每則是誰在說、偏向哪一邊。

## 來源 [#sources]

- **台灣公司申報的重大訊息**，以及內部人申報的持股轉讓。
- **PTT 股票板。**
- **新聞媒體的報導，以及 Threads 與 X 的貼文**，透過你的[網路搜尋金鑰](/zh-TW/docs/setup/web-search)。

沒有網路搜尋金鑰時，只會讀取重大訊息、內部人轉讓與 PTT。

## 總覽上 [#on-the-overview]

總覽 **消息** 分頁上的 **近期重大消息**，會排序過去一週你持有與自選標的的新聞：公司自己說的比媒體重，媒體比投資人重，財報比市場閒談重。

## 多久收集、保留多久 [#how-often-and-for-how-long]

| 設定                 | 預設       | 位置                             |
| -------------------- | ---------- | -------------------------------- |
| 收集庫存與自選的新聞 | 每 72 小時 | 設定 → 排程 → App 自己收集的資料 |
| 收集主題的新聞       | 每 24 小時 | 設定 → 排程 → App 自己收集的資料 |
| 新聞保留期限         | 90 天      | 設定 → 儲存空間                  |
| 社群保留期限         | 30 天      | 設定 → 儲存空間                  |

收集頻率可以設為每 6 或 12 小時、每天、每 3 或 7 天，或每天固定時間；**立即收集** 會馬上執行一次。新聞可以保留 30、90 或 180 天、1 年，或不刪除。
