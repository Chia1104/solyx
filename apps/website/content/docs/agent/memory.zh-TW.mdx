Agent 會把它對你交易方式的了解存成記憶，跨對話保留；你可以在 **設定 → 記憶** 閱讀、編輯與遺忘它們。

| 類型     | 內容                   |
| -------- | ---------------------- |
| 關於你   | 你是誰，以及你怎麼交易 |
| 工作方式 | 你希望 Agent 怎麼工作  |
| 筆記     | 其他值得保留的事       |

## 儲存與遺忘 [#saving-and-forgetting]

- 在 **先詢問** 下，記憶要等你允許才會儲存。在 **自動判斷** 下，新的筆記不經詢問就會儲存，這次呼叫也會註明這一點；改寫記憶，或儲存「關於你」與「工作方式」的記憶，仍會先等你允許。
- 遺忘一律先等你允許，除非對話設為 **不詢問**。
- 一則記憶的描述最多 150 個字元，細節最多 2,000 個字元。看起來像金鑰或身分證字號的內容會被拒絕。
- 有本機嵌入模型時，和 Agent 已有的某則記憶太相近的新記憶會被拒絕，並引導 Agent 改看那一則。

## 每段對話都會讀的內容 [#what-every-conversation-reads]

每段對話開始時會讀一份記憶索引：先列「關於你」與「工作方式」，再列筆記，各自由新到舊，總長在 8,000 個字元以內；其餘的可以透過搜尋回想。

關閉 **使用記憶** 後，記憶仍會保存，但既不會被讀取，也不會寫入新的。
