Agent 談的是你畫面上的東西。訊息會帶著你正在看的個股，連同它圖表的週期與指標，或是總覽目前的分頁；**不附加** 會讓這則訊息不帶畫面上的內容。

## 和它對話 [#talking-to-it]

- **`@`** 指定其他個股：先列畫面上的，再列你持有的，然後是你自選的。
- **`/`** 呼叫 skill 或指令。`/compact` 會把較早的訊息整理成摘要以騰出上下文空間，並保留你在指令後寫下的重點。
- **模型與思考程度** 在輸入框中依對話選擇，從你的[預設值](/zh-TW/docs/setup/models#the-default-model)開始。
- **上下文用量** 顯示對話佔了模型視窗的多少。快滿時，較早的訊息會整理成摘要；**整理較早的訊息** 會立刻這麼做。每則回覆的 **Token 用量** 會列出輸入、從快取讀取、寫入快取與回覆的 token 數。
- **回覆** 可以畫圖，也就是一張用 App 自己配色的畫布，沒有腳本也不連網路；也可以連結到 App 內的頁面。連到網路的連結會先詢問再開啟。
- **編輯成新訊息** 會從你的某則訊息重新開始。

## 它讀什麼 [#what-it-reads]

- **它引用而不是自己算的數字**。它的工具讀取 K 線、技術指標、財報、籌碼、經濟數據、行事曆、新聞與你的帳戶。成長率、利潤率與各種倍數由 App 算好，模型只負責引用。[Solyx 怎麼計算](/zh-TW/docs/data)。
- **它自己的分析**。它寫的腳本在沙盒中執行，只能讀取行情、籌碼、財報與帳戶，其他什麼都碰不到：不能連網路，也不能存取檔案。
- **網路**，透過你的 [Firecrawl、Exa 或 Tavily 金鑰](/zh-TW/docs/setup/web-search)。
- **它對你的了解**。[記憶](/zh-TW/docs/agent/memory)會跨對話保留；每一則你都能閱讀、編輯與遺忘。

## 它的動作怎麼放行 [#how-its-actions-are-allowed]

每段對話都能選擇 Agent 的工具呼叫與 shell 指令要怎麼放行。

| 模式     | 不需要你就會執行的                                                                              |
| -------- | ----------------------------------------------------------------------------------------------- |
| 先詢問   | 沒有：工具呼叫與 shell 指令都先等你允許。                                                       |
| 自動判斷 | 決策模型判斷為無害的 shell 指令、讀取本對話找到的網頁，以及把對你的了解存進記憶。其餘仍先詢問。 |
| 不詢問   | 工具呼叫與 shell 指令。                                                                         |

沒有[決策模型](/zh-TW/docs/setup/decisions)時，**自動判斷** 會對每個 shell 指令先詢問。等待中的呼叫會顯示它要做什麼，並附上 **允許** 與 **不允許**；未經詢問就執行的呼叫會說明原因。

<Callout type="warn" title="沒有任何模式能確認委託">
  它的工具只能提出：由你在 App
  裡按住確認，或由你設定的[交易授權](/zh-TW/docs/orders/mandate)送出落在範圍內的提案。
</Callout>

## 它能變更什麼 [#what-it-can-change]

在你要求時，Agent 可以讀取你的設定，並變更其中幾項：外觀主題、配色、漲跌顏色、語言與時區、行情來源與方案、預設模型與思考程度、決策模式、新聞與主題的收集頻率、網路搜尋與決策模型的供應商、嵌入模型，以及檢查更新。除非對話設為 **不詢問**，每項變更都會先等你允許。

它永遠改不了金鑰或登入、啟用了哪些供應商、端點、shell、MCP 工具的放行規則、共用的 skills、記憶、選單列、備份的目的地、委託送往的帳戶、交易授權或下單鎖定。

## 它的工具 [#its-tools]

<Accordions>
  <Accordion title="行情與帳戶">
    各市場的交易時段與當地時間；K
    線；技術指標與關鍵價位；多檔標的的報價；新聞與其情緒評分；分量最重的頭條；行事曆；自選；以及帳戶的現金、庫存、委託中的單、停損停利與已平倉的每一趟交易。
  </Accordion>
  <Accordion title="委託">
    列出提案、不提出也能先用風控檢查核對一筆委託、提出委託，以及提出停損或停利。除此之外什麼都不能做。
  </Accordion>
  <Accordion title="研究">
    報告與預測、財報、基準率、修訂報告、提交預測、籌碼、經濟數據、類股與產業主力、類股輪動，以及搜尋保存的研究、新聞與提案。
  </Accordion>
  <Accordion title="網路、記憶與主題">
    搜尋網路與讀取網頁；回想、記住與遺忘；讀取主題、搜尋某個主題，以及儲存主題。
  </Accordion>
  <Accordion title="任務、自選與設定">
    讀取排程任務與執行紀錄、立即執行一個任務、儲存任務；變更自選；讀取設定與變更某項設定。
  </Accordion>
  <Accordion title="腳本與擴充">
    讀取 skill；在沙盒中執行分析腳本；搜尋並呼叫 MCP server
    的工具，或用腳本串接它們；以及在你開啟時使用 shell。
  </Accordion>
</Accordions>

網路工具只在有網路搜尋金鑰時提供，記憶工具也只在記憶開啟時提供。
