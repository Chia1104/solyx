排程任務會自己傳訊息給 Agent，每次執行都在獨立的對話中，並會用掉你模型的 token。Solyx 縮在選單列時，排程仍會照常執行。

## 建立任務 [#making-a-task]

在 **設定 → 排程 → 排程任務**，或直接請 Agent 幫你，為任務設定 **名稱**、**要送出的內容** 與 **何時**。

<Tabs items={["每隔一段時間", "每天固定時間", "有變化時"]}>
  <Tab value="每隔一段時間">
    每 30 分鐘、每小時、每 2、4、6 或 12
    小時，或每天。從任務儲存或上次執行之中較晚的那一刻起算。
  </Tab>
  <Tab value="每天固定時間">
    依你的時鐘在某個時間執行：每天、台股交易日或美股交易日。Solyx
    關著而錯過的時間，12 小時內仍會補執行；更早的就略過。
  </Tab>
  <Tab value="有變化時">
    當報告的反證條件成立、報告記下的日期已過，或主題的觀察訊號出現時執行，範圍可以是你所有的庫存與自選，或你指定的個股與主題。Solyx
    每半小時檢查一次，在你設定的間隔內最多執行一次。
  </Tab>
</Tabs>

**需要詢問的呼叫** 可以選 **等我回答**（預設）或 **判定無害的直接放行**。排程執行絕不會使用 **不詢問**。任務的每次執行會在你的對話中標為 **排程**，**開啟對話** 會顯示最近一次。**立即執行** 會馬上執行一次。

`watchlist-upkeep` skill 很適合當任務：巡一輪自選，最後給出簡報。

## App 自己收集的資料 [#what-the-app-collects]

在任務上方，**App 自己收集的資料** 設定 Solyx 不經模型、自動收集資料的頻率：

| 項目             | 預設       |
| ---------------- | ---------- |
| 庫存與自選的新聞 | 每 72 小時 |
| 主題的新聞       | 每 24 小時 |

每一項都可以設為每 6 或 12 小時、每天、每 3 或 7 天，或每天固定時間；**立即收集** 會馬上收集一次。[網路搜尋](/zh-TW/docs/setup/web-search#staying-within-a-free-tier)。
