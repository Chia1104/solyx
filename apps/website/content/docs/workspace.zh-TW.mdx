## 標題列 [#the-title-bar]

由左到右：自選的開關、**返回**、Solyx 的名稱（點了會開啟總覽）、代號搜尋、有更新時的更新按鈕、各市場的交易時段、下單鎖、目前是模擬交易還是真實交易、[**策略**](/zh-TW/docs/strategies#the-strategies-page)、**設定**，以及 Agent 窗格的開關。

標題列下方有一條線：委託送往模擬帳戶時，它是鉛筆斜線；送往你自己的帳戶後，就變成實心的墨水線。

## 自選與庫存 [#watchlist-and-positions]

左欄先列出你的 **自選**，再列出 **庫存**。每一列有名稱、當日走勢線、價格與今日漲跌，庫存另外附上損益。搜尋代號後，按圖表上方的星號加入自選。拖曳一列可以調整順序；按它的 ✕ 移除。

## Agent 窗格 [#the-agents-pane]

四個分頁：**對話**、**交易**、**買賣** 與 **損益**。**交易** 會顯示有幾筆提案在等你確認。切換分頁時，**買賣** 會保留填到一半的內容。[Agent](/zh-TW/docs/agent) 與[下單面板](/zh-TW/docs/orders/order-panel)。

## 選單列 [#the-menu-bar]

視窗關閉時，Solyx 會留在選單列（Windows 則是系統匣），所以排程任務與停損停利會繼續執行。它的選單列出等你處理的事：要確認的提案與要允許的呼叫，正在執行的排程任務與接下來的三個，以及有更新時的更新。點一列只會在對應的位置打開視窗：選單裡沒有任何東西能確認委託或允許呼叫。圖示會顯示有幾件事在等你，Dock 也一樣。

在 **設定 → 一般 → 背景執行** 可以關掉 **讓 Solyx 常駐選單列**；在 macOS 上開啟 **沒有視窗時離開 Dock**，沒有視窗時就不會出現在 Dock。

## 鍵盤快捷鍵 [#keyboard-shortcuts]

| 按鍵                               | 作用                  |
| ---------------------------------- | --------------------- |
| <kbd>⌘ B</kbd> / <kbd>Ctrl B</kbd> | 顯示或隱藏自選        |
| <kbd>⌘ I</kbd> / <kbd>Ctrl I</kbd> | 顯示或隱藏 Agent 窗格 |
| <kbd>⌘ K</kbd> / <kbd>Ctrl K</kbd> | 搜尋代號              |
| <kbd>⌘ [</kbd> / <kbd>Alt ←</kbd>  | 返回                  |
| <kbd>Enter</kbd>                   | 送出訊息              |
| <kbd>Shift Enter</kbd>             | 在訊息中換行          |

拖曳分隔線可以調整欄寬，也可以聚焦後用方向鍵調整；雙擊可以還原。**按住送出** 需要按住 1.2 秒，螢幕閱讀器的按下動作可以代替按住。

## 設定 [#settings]

**設定** 會取代自選欄，列出它的各個分頁：最上面是 **一般**，接著是五個群組，最後是 **可觀測性** 與 **關於**。

| 群組           | 分頁                               |
| -------------- | ---------------------------------- |
| **交易**       | 行情、券商、下單                   |
| **Agent**      | 模型、Skills、MCP、記憶、排程      |
| **新聞與研究** | 網路搜尋、決策模型、新聞合併、主題 |
| **安全**       | 程式執行、裝置                     |
| **資料**       | 儲存空間、備份                     |

點群組標題可以把它收起，Solyx 會記住你收起了哪些；打開某個分頁時，不論是從這裡或從連結，它所在的群組都會展開。較長的編輯會在頁面上方開一個視窗，例如排程任務、主題、記憶、交易授權或 MCP server 的工具。點視窗外面不會關閉它，也不會丟掉你打的內容；按 **取消**、關閉按鈕或 <kbd>Esc</kbd> 才會離開。

## 外觀 [#appearance]

在 **設定 → 一般**：

- **主題**：跟隨系統、淺色或深色。
- **配色**：淺色與深色各選一套，可從藍圖、石墨、茶褐、鳶尾、潟湖、明日香、綾波零、初號機、真希波、電馭叛客與露西中挑選。複製一套就能編輯它的底色、文字、線條與強調色。
- **漲跌顏色**：依市場慣例（台股紅漲、美股綠漲），或不分市場一律紅漲綠跌、綠漲紅跌。
- **語言** 與 **時區**。
