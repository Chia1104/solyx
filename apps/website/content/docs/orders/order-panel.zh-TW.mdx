右側窗格有四個分頁：**對話** 是和 Agent 的對話與對話紀錄；**交易** 列出等你確認的提案、委託中的單、最新成交與過去的提案；**買賣** 是下單面板；**損益** 顯示各幣別的未實現損益與現金、每檔庫存以現價計算的損益，以及已平倉部位的已實現損益，附累積走勢與每一趟的盈虧。

## 填單 [#filling-it-in]

在個股頁，面板會直接交易那一檔；其他地方則輸入代號並選擇市場。行情來源查得到這個代號，面板才會開啟，所以打錯代號不會建立任何提案。

<Steps>
  <Step>**選買賣與數量。** 台股以張計，零股以股計。</Step>
  <Step>
    **設定價格。**
    在你自己設定之前，價格會跟著最新成交價：可以一次升降一檔、從圖表旁的五檔點選價格，或直接帶入跌停、平盤、現價、漲停。圖表上方準星圖示的
    **點價**，會把你下一次在圖上點的位置帶成委託價。
  </Step>
  <Step>
    **再讀一遍。**
    填單時，整筆委託會用鉛筆寫成一句話，附上價金、手續費，賣出時再加上交易稅。
  </Step>
  <Step>
    **檢查委託。**
    這會用它建立一筆提案，就在正下方等你確認，也會和其他提案一樣列在
    **交易**。之後再改面板，這筆提案就會放棄。
  </Step>
</Steps>

## 圖表上 [#on-the-chart]

圖表會畫出帳戶在這檔的動作：

| 畫法         | 代表                    |
| ------------ | ----------------------- |
| 墨水（實線） | 持股均價與委託中的單    |
| 點線         | 券商盯價中的停損停利    |
| 鉛筆虛線     | 還在等待的提案          |
| 箭頭         | 每根有買進或賣出的 K 棒 |
| 邊緣的線     | 當日漲跌停              |

**分時** 和其他週期一起放在標示目前 K 棒週期的按鈕裡，以 1 分 K 畫出最新一個交易時段：以參考價為界上下著色，附均價線與成交量，時間軸涵蓋整個交易時段。

## 五檔與你的庫存 [#the-order-book-and-your-holding]

圖表上方長條圖示的 **五檔**，會顯示當日統計與今天在漲跌停之間走過的區間、最佳五檔買賣價，以及你在這檔的庫存（以現價計算）。圖表下方的 **委託與成交** 列出這檔委託中的單與最新成交。

在庫存上按 **賣出** 或 **停損停利**（這裡、**損益** 或總覽都可以），會打開下單面板並帶入可賣的股數。要等你按檢查才會建立提案。
