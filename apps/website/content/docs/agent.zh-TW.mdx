Agent 談的是你畫面上的東西。對話會帶著你正在看的股票；用 `@` 指定其他股票，用 `/` 呼叫操作手冊（skill）。

## 它讀什麼

- **它引用而不是自己算的數字**。它的工具讀取 K 線、技術指標、財報、籌碼、經濟數據、行事曆、新聞與你的帳戶。成長率、利潤率與各種倍數由 App 算好，模型只負責引用。
- **它自己的分析**。它寫的腳本在沙盒中執行，只能讀取行情與帳戶，碰不到其他東西。
- **網路**，透過你的 Firecrawl、Exa 或 Tavily 金鑰。
- **它對你的了解**。記憶會跨對話保留；每一則你都能閱讀、編輯與遺忘。

## 它的動作怎麼放行

每段對話都能選擇 Agent 的工具呼叫與 shell 指令要怎麼放行。

| 模式     | 不需要你就會執行的                                                                      |
| -------- | --------------------------------------------------------------------------------------- |
| 先詢問   | 沒有：工具呼叫與 shell 指令都先等你允許。                                               |
| 自動判斷 | 判斷為無害的 shell 指令、讀取本對話找到的網頁，以及把對你的了解存進記憶。其餘仍先詢問。 |
| 不詢問   | 工具呼叫與 shell 指令。                                                                 |

沒有任何模式能讓 Agent 確認委託。它的工具只能提出：由你在 App 裡按下確認，或由你設定的[交易授權](/zh-TW/docs/orders#交易授權)送出落在範圍內的提案。

## 你的擴充

- **操作手冊（skills）**放在 `~/.solyx/skills/`，以 `/` 指令提供。
- 同一個資料夾裡的 **`AGENTS.md`** 放著 Agent 每次執行都會讀的長期指示。
- **`mcp.json`** 用來連接 MCP 伺服器。它們的每個工具都可以設為關閉、詢問或自動。

## 排程

排程任務會定期傳訊息給 Agent：在市場有交易的日子的某個時間，或在 App 觀察的東西有變化時。App 縮在選單列時，排程仍會照常執行。排程執行只會用「先詢問」或「自動判斷」，絕不會在「不詢問」下執行。

## 模型

使用模型服務商的 API 金鑰，或登入你已經有的方案：ChatGPT、GitHub Copilot、xAI 或 Meta。每段對話都可以另外選擇模型與思考程度。
