Nightly builds for macOS (`.dmg`) and Windows (`.exe`) are on the [download page](/download). A nightly is built from the newest commit that passed its checks, at most once every six hours.

## First launch

Solyx has no paid signing certificates yet. The macOS app is ad-hoc signed and the Windows installer unsigned, so the system warns you before the first launch.

A nightly installs as Solyx Nightly and keeps its own data, so it never touches a stable install's settings, keys or databases. The first time it opens, Solyx walks you through what it needs. [Keys and sources](/docs/setup).

## Updates

Solyx checks its channel for updates a minute after it starts, every six hours after that, and whenever you press **Check now** under **Settings → About**. **Check for updates** there switches the automatic checks off.

<Tabs items={["Windows", "macOS"]}>
  <Tab value="Windows">
    Solyx downloads the update and installs it when it restarts or quits;
    **Restart to update** at the foot of the left column does it now.
  </Tab>
  <Tab value="macOS">
    Solyx tells you a newer version is out, and **Download update** links to its
    release, since installing in place needs a Developer ID signature.
  </Tab>
</Tabs>

A development build, and Linux, never check.

## Where Solyx keeps things

- **Settings** live in `~/.solyx/config.json`. You may edit it by hand; Solyx applies saved changes without a restart and never overwrites a file with syntax errors.
- **Keys and sign-ins** are saved encrypted with your system's secret store, and never in the config file, a log or a backup.
- **Your instructions for the agent** sit beside the config: `skills/`, `AGENTS.md` and `mcp.json`.

[Every file, and what config.json holds](/docs/files).

## Build it yourself

Solyx needs [Vite+](https://viteplus.dev/) (`vp`) and Node.js 26 or later.

```bash
vp install           # install dependencies
vp run dev:desktop   # start the desktop app in development mode
vp run ready         # check, test and build
```

A development build runs as Solyx Dev, with its own settings and keys.
