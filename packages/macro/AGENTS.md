# `@solyx/macro`

Schedules of economic releases and the figures they bring, the rate between the app's two currencies and US Treasury yields, one module per source, each implementing `MacroCalendarProvider` or `MacroFiguresProvider` from `@solyx/core/macro`, `ExchangeRateProvider` from `@solyx/core/exchange-rate` or `YieldCurveProvider` from `@solyx/core/yields`. `./stat-gov-tw` reads Taiwan's schedule from the national statistics portal's release calendar, which lists each agency's releases for the coming twelve months. `./dgbas` reads Taiwan's figures from the macro database of the Directorate-General of Budget, Accounting and Statistics, which gathers the other agencies' too and whose API needs no key. `./longbridge` reads the US's schedule and figures alike from Longbridge's macro data on the user's sign-in, through the `LongbridgeApi` its other readers share: each followed series with what the market expected of each period, the time each came out, and the next once Longbridge schedules it, a few weeks ahead. `./cbc` reads the US dollar's rate in Taiwan dollars from the central bank's open data, each business day's close of the interbank market, whose API needs no key and answers every close since 2008 at once, since it takes no range. `./treasury` reads US Treasury debt's daily par yield curve from the Treasury's own files, a year to a file, which need no key and are the government's work, free of copyright; it finds each tenor's column by the name the file's first line gives it, so a file that drops one fails rather than reading another as it.

## Boundaries

- A module follows a fixed list of releases that move the market, each named by the source's own id for it, never by its title, and maps each to a `MacroIndicator`; the rest of a source's calendar is left out.
- Drop an entry that does not parse, so one odd entry never hides the rest. A day the source gives only as a latest day is a `Deadline`. A release's page is the first its source links that is an https address, since a source lists the agency's news before its databases, and a time that does not read is left empty rather than dropping its day.
- A figures module follows a fixed list of tables and figures by the source's own codes, and checks what the source names each item it reads, so a renumbered table fails rather than passing another figure off as the one followed. One table failing fails the read, since figures that come only in part would be taken for whole.
- `./longbridge` reads its series' names in English, which tell a series' measure apart where Longbridge's Chinese names of several read alike. A series names its periods by their first day, so it writes a month's, a quarter's or a week's last day by the series' cycle, and a central bank's decision by the day it was announced in New York. An indicator's series that come out together are one release a day, which takes its headline series' period; a point not out yet has no figure, so it only schedules a release and carries what is expected of the next period.
- `./dgbas` asks the database's API in the ways its document leaves out: a query names three dimensions whatever its table has, a query it does not take answers the table's web page rather than an error, a period not out yet answers 0, so a series ends at its newest period that is not 0, and a request now and then hangs for minutes while the same one sent again is answered at once, so one that times out is sent again. It reads levels alone and leaves growth to `@solyx/core/macro`.
