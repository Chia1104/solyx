# `@solyx/macro`

Schedules of economic releases and the figures they bring, the rate between the app's two currencies and US Treasury yields, one module per source, each implementing a provider contract of `@solyx/core/macro`, `@solyx/core/exchange-rate` or `@solyx/core/yields`. `./stat-gov-tw` reads Taiwan's schedule from the national statistics portal's release calendar, and `./dgbas` its figures from DGBAS's macro database, which gathers the other agencies' too. `./longbridge` reads the US's schedule and figures alike from Longbridge's macro data through the sign-in's one `@solyx/longbridge` client. `./cbc` reads the US dollar's rate in Taiwan dollars, each business day's interbank close, from the central bank's open data. `./treasury` reads the Treasury's daily par yield curve from its own files, a year to a file, which are the government's work, free of copyright.

## Boundaries

- A module follows a fixed list of releases that move the market, each named by the source's own id for it, never by its title, and maps each to a `MacroIndicator`; the rest of a source's calendar is left out.
- Drop an entry that does not parse, so one odd entry never hides the rest. A day the source gives only as a latest day is a `Deadline`. A release's page is the first its source links that is an https address, since a source lists the agency's news before its databases, and a time that does not read is left empty rather than dropping its day.
- A figures module follows a fixed list of tables and figures by the source's own codes, and checks what the source names each item it reads, so a renumbered table fails rather than passing another figure off as the one followed. One table failing fails the read, since figures that come only in part would be taken for whole.
- `./treasury` finds each tenor's column by the name the file's first line gives it, so a file that drops one fails rather than reading another as it. `./cbc`'s API takes no range and answers every close since 2008 at once.
- `./longbridge` reads its series' names in English, which tell a series' measure apart where Longbridge's Chinese names of several read alike. A series names its periods by their first day, so it writes a month's, a quarter's or a week's last day by the series' cycle, and a central bank's decision by the day it was announced in New York. An indicator's series that come out together are one release a day, which takes its headline series' period; a point not out yet has no figure, so it only schedules a release, a few weeks ahead, and carries what is expected of the next period. The schedule and the figures come from the same series, which a window asks for together, so one read of each series' newest points serves both for a few minutes, since Longbridge's HTTP API takes a read only every quarter of a second.
- `./dgbas` asks the database's API in the ways its document leaves out: a query names three dimensions whatever its table has, a query it does not take answers the table's web page rather than an error, a period not out yet answers 0, so a series ends at its newest period that is not 0, and a request now and then hangs for minutes while the same one sent again is answered at once, so one that times out is sent again. It reads levels alone and leaves growth to `@solyx/core/macro`.
