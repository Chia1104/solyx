# `@solyx/longbridge`

Longbridge's OpenAPI on the user's sign-in, which every Longbridge reader in the app goes through: `./sign-in` holds the OAuth calls a sign-in makes, `./wire` the quote server's protocol, and `./client` one sign-in's HTTP API and quote server under one budget. What Longbridge's answers mean for the app, such as a bar, a filing or an economic figure, is read in the package of its kind (`@solyx/market-data`, `@solyx/fundamentals`, `@solyx/news`, `@solyx/macro`), each through the one client.

## Boundaries

- Longbridge counts an account's quote requests together, over HTTP and over its quote server alike: ten a second and five waiting for an answer at once. The client keeps every request of a sign-in within that one budget, each quote command to the pace the server tells each connection as it opens, and HTTP reads, whichever endpoint, a quarter of a second apart, since its HTTP API refuses reads closer than that or a few at once whatever its documents say. The services make one client and hand it to every reader. A request counts as it goes out rather than as it waits, each second counted a little long for the network's jitter, and one held back only by its own pace lets others go first. One refused as too fast holds back every request of its kind for the pause Longbridge names, in a `Retry-After` or in its message, or else a growing one, and is then asked again through the budget, a few times; the client tells its owner of each refusal.
- The quote server takes one connection per sign-in, which the first request opens with a one-time password fetched with the access token, and which pushes ride too. A connection that closes, refuses or stops answering is dropped with its requests, and the next request opens another; the runtime's `WebSocket` hides the server's pings, so a heartbeat goes every 30 seconds.
- `./wire` writes out by hand the few messages the app sends or reads, from the documented field numbers, since Longbridge's `.proto` files carry no licence. It speaks Longbridge's shapes, decimal text and its own numbering, and leaves the app's shapes to the readers.
- `./sign-in` registers a client per sign-in, exchanges the PKCE code, refreshes, which rotates the refresh token, and deletes the client. It asks for the narrowest scope Longbridge grants, the watchlist, since quotes need none.
