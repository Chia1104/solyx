# `@solyx/longbridge`

Longbridge's OpenAPI on the user's sign-in, which every Longbridge reader in the app goes through: `./sign-in` holds the OAuth calls a sign-in makes, `./wire` the quote server's protocol, and `./client` one sign-in's HTTP API and quote server under one budget. What Longbridge's answers mean for the app is read in the package of its kind (`@solyx/market-data`, `@solyx/fundamentals`, `@solyx/news`, `@solyx/macro`), each through the one client.

## Boundaries

- Longbridge counts an account's quote requests together, over HTTP and its quote server alike: ten a second and five waiting for an answer at once. The services make one client per sign-in and hand it to every reader, and it keeps every request within that budget: each quote command to the pace the server tells each connection as it opens, and HTTP reads, whichever endpoint, a quarter of a second apart, since the HTTP API refuses reads closer than that or a few at once whatever its documents say. A request counts as it goes out rather than as it waits, each second counted a little long for the network's jitter, and one held back only by its own pace lets others go first. One refused as too fast holds back every request of its kind for the pause Longbridge names, in a `Retry-After` or its message, or else a growing one, and is then asked again through the budget a few times; the client tells its owner of each refusal.
- The quote server takes one connection per sign-in, which pushes ride too, opened by the first request with a one-time password fetched with the access token. A connection that closes, refuses or stops answering is dropped with its requests, and the next request opens another; the runtime's `WebSocket` hides the server's pings, so a heartbeat goes every 30 seconds. What throws out of the socket's listener ends the process, so a packet that does not read, or that a push's listener cannot take, is left out and the client tells its owner of it; a request whose answer did not read ends as an unanswered one does.
- `./wire` writes out by hand the few messages the app sends or reads, from the documented field numbers, since Longbridge's `.proto` files carry no licence. It speaks Longbridge's shapes, decimal text and its own numbering, and leaves the app's shapes to the readers.
- `./sign-in` registers a client per sign-in, exchanges the PKCE code, refreshes, which rotates the refresh token, and deletes the client. It asks for the narrowest scope Longbridge grants, the watchlist, since quotes need none.
